## 不變的安全與真實性界線

研究自主不等於風險或實盤授權。現階段仍是工程建置與影子驗證，不提出可執行的真實交易。
不接觸 API key，不送真實單，不碰 Main CIO 或其他帳戶。
不建議提高風險檔位或有效曝險，也不把使用者的高槓桿想法轉成設定。
風險數值沒有設定就拒絕 paper 開倉，不直接繼承 SPEC 的範例數字。
策略虧損後不調參救帳，變更只能写成提案待核准。工程 bug 修復與策略改版分開記錄。
若更換訊號或成交模型，保存舊版與全部舊結果，建立新版本，不覆寫歷史。

## 資料與顯示口徑

lab/shared/status.json 是同一份行情與影子狀態快照，供 UI 與簡報讀取。
100 USDT 為使用者指定的影子初始數額。實際 Binance 錢包餘額未知，不在沒有憑證的情況下聲稱已讀取。
如果沒有成交，零 PNL 明示為「未交易」，不能解讀為策略穩定或證明正期望。
行情過期、API 失敗或服務停機都顯示明確失效狀態，不把歷史快照說成即時。
初版採公開 REST 輪詢，不能宣稱已達 websocket 成交粒度或完成悲觀成交驗證。

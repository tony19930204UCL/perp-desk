# 自主工作與路線圖觀察台

狀態：需求已登記，尚未送達 ChatGPT，未實作。這是 Monitor（觀察）介面，不是操作控制台。

## 使用者的問題
不用問助理，也能知道目前在哪個階段、實際在做什麼、有哪些規劃、為何受阻，以及最近到底產出什麼。C-0026、C-0028 等自動新增或長期排程的工作也必須看得到。不是把帳本 JSON 美化後全標成進行中。

## 產品設計授權
ChatGPT 擔任產品設計與前端實作負責人。先調查既有程式與資料契約，提出不同資訊架構並自行選出適合的方案，再實作可運作動態頁面。不要求觀察員逐項選版型。可沿用既有看板的深色與資訊密度，但工作觀察與交易帳務分頁，不因本功能延後整個頁面。整合既有 UI 工程，不重建第二套任務管理系統。

## 資料來源與界線
本機權威來源：commitments/ledger.json、cron/jobs.json、lab/journal/roadmap.json、lab/shared/work_status.json、lab/journal/entries.jsonl 及經核實的任務執行結果。先讀目前 dashboard API、roadmap/ledger/排程契約再設計。公開 GitHub 只能放 source、去識別契約與測試 fixture，不放真帳本、主機資訊、私人草稿、原始 log、憑證或個人資料。source/config 使用可設定 profile root，不硬編本機路徑。

## 最小可用成果
1. 當前階段與退出門檻：紙盤可靠性、前瞻策略驗證、實盤準備等依真 roadmap 呈現。展示本階段必做、已驗收、受阻項目與依賴。日期是目標，不是假承諾。實盤準備不等於實盤授權。
2. 實際執行區：真 worker/可核實執行身分、目前步驟、開始及最後進度、對應 C-ID/PR/證據。只登記為 running 卻沒有可核實 executor 的工作顯示『活動未確認』，不得偽裝正在跑。
3. 持續排程區：C-0026/C-0028 這類顯示頻率、最近應執行、最近實際執行/結果、下一次時間與成果新鮮度。『已排程、目前閒置』與『本輪執行中』分開。週任務不能套固定72小時誤報。cron ok 不是成果已驗收。
4. 計畫/阻擋/自主延後：列出下一步、真正阻擋、依賴鏈、延後原因及重評日。未派工就是未派工，不顯示模糊百分比。支持狀態、類別、階段篩選與 C-ID 搜尋。
5. 任務詳情：原承諾、為什麼做、驗收條件、目前已知事實、下一步、實際執行持有人、更新紀錄、來源時間及衝突警告。區分完成工程、已部署、已證實無人值守閉環。
6. 最近產出：研究結論、驗收結果、部署與失敗事件的安全摘要及可讀證據引用，不能把模型有回覆當完成。舊結果保留。
7. 動態刷新及明確的新鮮度。資料缺失、錯誤、過期或來源互相矛盾須顯示，不用0或空清單假裝健康。若歷史 C-ID 無對應 roadmap，顯示尚未分類，不默默丟掉。

## 安全與效能
loopback 唯讀，沒有開始/停止/核准/改策略/改帳本按鈕。不讀其他 profile，不提供任意檔案瀏覽/API。保留 Host/Origin/跨站與路徑檢查。對外部文字用 textContent。避免每次刷新讀整個巨大交易 DB 或整份歷史 log。頁面自動更新不等於助理持續思考，明示資料來源與執行模型界線。

## 驗收
真實來源到畫面欄位對照，計數以程式核對且不漏任務。隔離 fixture 覆蓋執行中、死 worker、只登記 running、排程閒置、週期未到、漏跑、執行失敗、成功但缺成果、阻擋已解除、延後過期、時間/來源衝突、缺檔及壞 JSON。桌機與手機的真 browser 截圖、刷新後狀態變化、搜尋/篩選/詳情、可及性與 readonly API 安全。提供實際命令、測試結果、精確 head、雙 CI、部署/啟動方法及未完成項。助理驗功能與真實性，使用者驗視覺。未部署不提供假 live 網址。

## 工程接力
2026-10-15 使用者明確授權本需求現在透過獨立新分頁平行派工，不再等 PR62。PR62 原聊天室、CA1-r3 卡及 AP3 原不確定派工完全不操作、不重送。新 job 使用獨立 request-file/lock、精確 tab target/ChatUrl、獨立 branch/draft PR/mailbox；模型可平行生成，browser inspect/approve 必須序列化並精確綁頁。現有 newest-job 自動核准器不具安全跨頁 admission 時，先用正常排程管理停用並讀回，不能把不安全入口留著稱安全並行。正式派送須保留確切單次 rendered user bubble、URL 及監看持有人。可先交工作觀察頁，不必等交易帳務看板所有功能完成；與 C-0112 既有 UI 整合並保留帳務功能，不另造管理平台。工程只走授權非 main 分支/draft PR，禁止 merge main、部署、實盤、修改交易 DB 或策略。
